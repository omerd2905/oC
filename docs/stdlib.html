oc-std, oc-syscalls — Core runtime primitives, regional arena memory allocators, hardened filesystem abstractions, network wire routines, checked math, and direct Linux x86_64 kernel syscall intrinsics.

OC-SYSCALLS(2) — Direct Linux x86_64 Syscalls (Zero-Libc ABI)

Unlike traditional C/C++ runtimes that require dynamic linking against libc.so.6 (or bundling a 850 KB static musl/glibc runtime), the occ compiler emits the direct x86_64 kernel machine code instruction sequence (0x0f 0x05) directly into standalone static ELF executables.

Kernel Transition: oC bypasses userspace wrappers entirely. The occ backend (compiler/elf.oc) assigns register operands according to the System V AMD64 Syscall Calling Convention and emits a 2-byte syscall instruction.

Linux x86_64 kernel ABI register convention strictly enforced by occ:

Register Syscall Role oC Runtime Binding
%rax Syscall Number & Kernel Return Value Loaded with literal syscall number before syscall; holds return value / error code (< 0 is -errno)
%rdi Argument 1 1st parameter (e.g. file descriptor fd or memory address addr)
%rsi Argument 2 2nd parameter (e.g. buffer pointer buf or length len)
%rdx Argument 3 3rd parameter (e.g. byte count count or protection flags prot)
%r10 Argument 4 4th parameter (Kernel replaces %rcx with %r10 for syscall ABI, e.g. flags)
%r8 Argument 5 5th parameter (e.g. backing file descriptor fd for mmap)
%r9 Argument 6 6th parameter (e.g. file offset off for mmap)

Full Reference Table: 11 Direct Linux Intrinsics

Syscall Nr Intrinsic Function Signature Description & Kernel Contract
0 sys_read(fd: i32, buf: *mut u8, count: usize) i64 Reads up to count bytes from open file descriptor fd into buffer buf. Returns number of bytes read or -1 on error.
1 sys_write(fd: i32, buf: *u8, count: usize) i64 Writes up to count bytes to file descriptor fd from buffer buf. Returns bytes written or -1.
2 sys_open(path: *u8, flags: i32, mode: u32) i32 Opens or creates file at NUL-terminated path with specified POSIX flags and file permission bits. Returns non-negative fd or -1.
3 sys_close(fd: i32) i32 Closes open file descriptor fd. Returns 0 on success, negative error code on failure.
9 sys_mmap(addr: usize, len: usize, prot: i32, flags: i32, fd: i32, off: usize) *mut u8 Requests kernel virtual memory mapping of size len. Used with PROT_READ|PROT_WRITE (3) and MAP_PRIVATE|MAP_ANONYMOUS (34) to instantiate arenas. Returns base address or -1 (MAP_FAILED).
11 sys_munmap(addr: *mut u8, len: usize) i32 Unmaps len bytes of memory starting at addr, releasing physical frames immediately back to the kernel. Returns 0 on success.
41 sys_socket(domain: i32, sock_type: i32, proto: i32) i32 Creates an endpoint for network communication. E.g. sys_socket(2, 1, 0) creates an AF_INET SOCK_STREAM socket. Returns fd or -1.
42 sys_connect(fd: i32, addr: *sockaddr_in, len: u32) i32 Initiates a TCP connection on socket descriptor fd to target network address. Returns 0 on success or negative on failure.
60 sys_exit(code: i32) void Immediately terminates calling process with status code code. Performs zero userspace teardown hooks.
87 sys_unlink(path: *u8) i32 Deletes a name from the filesystem. If that name was the last link to a file and no processes have it open, the space is freed.
90 sys_chmod(path: *u8, mode: u32) i32 Changes file permissions at path according to bitmask mode (e.g. 493 decimal = 0755 octal).
Example: Standalone x86_64 Direct Syscalls (Zero Libc)
SRC: sys_direct.oc 
// Direct kernel invocation without libc runtime
extern fn sys_write(fd: i32, buf: *u8, count: usize) i64;
extern fn sys_mmap(addr: usize, len: usize, prot: i32, flags: i32, fd: i32, off: usize) *mut u8;
extern fn sys_munmap(addr: *mut u8, len: usize) i32;

fn main() i32 {
    let msg: string = "[KERNEL] Direct x86_64 syscall execution verified!\n";
    sys_write(1, msg.ptr, msg.len);

    // Map 4096 bytes anonymously (PROT_READ|PROT_WRITE=3, MAP_PRIVATE|MAP_ANONYMOUS=34)
    let page: *mut u8 = sys_mmap(0, 4096, 3, 34, -1, 0);
    *page = 79; // Store ASCII 'O'
    let unmap_rc: i32 = sys_munmap(page, 4096);
    return unmap_rc;
}
TERMINAL: Direct Execution 
$ occ build sys_direct.oc -o /tmp/sys_direct --backend native
$ /tmp/sys_direct
[KERNEL] Direct x86_64 syscall execution verified!
$ echo $?
0
Active Defense ABI Guarantee: Standalone ELF binary contains only .text, .rodata, and an entry-point stub that sets up %rdi and executes sys_exit upon return from main. There is no dynamic linker (/lib64/ld-linux-x86-64.so.2), rendering shared library hijacking (e.g. LD_PRELOAD) completely impossible.

OC-MEM(3) — `std/mem.oc` Regional Arena Allocator

The std/mem.oc module implements pure kernel-backed contiguous bump memory regions. General-purpose heaps (such as ptmalloc or jemalloc) are discarded to eliminate heap fragmentation and metadata corruption (CWE-122).

struct Arena

struct Arena { offset: usize, capacity: usize, buffer: *mut u8 }

Regional allocator descriptor. Tracks the total allocated virtual memory size (capacity), the current high-water allocation mark (offset), and the base virtual address (buffer) returned by sys_mmap.

arena_init

fn arena_init(capacity: usize) Arena

Allocates a new virtual memory region of capacity bytes directly from the Linux kernel using anonymous private paging (sys_mmap(0, capacity, 3, 34, -1, 0)). Returns an initialized Arena with offset = 0.

arena_alloc

fn arena_alloc(arena: *mut Arena, size: usize) *mut u8

Carves out a contiguous slice of size bytes from the arena. Guarantees 8-byte alignment and executes an explicit capacity guard: if arena.offset + size > arena.capacity, it safely aborts or returns (0).as(*mut u8) to prevent out-of-bounds pointer fabrication.

arena_reset

fn arena_reset(arena: *mut Arena) void

Active Defense CWE-14 Scrubbing: Iterates across the allocated buffer from index 0 up to arena.offset, setting every byte to 0 to destroy transient cryptographic keys or passwords in RAM. Resets arena.offset = 0. Backing kernel pages remain mapped for high-throughput reuse. The compiler's EscapeValidator statically invalidates all previously borrowed pointers to this arena.

arena_deinit

fn arena_deinit(arena: *mut Arena) void

Performs CWE-14 zero-scrubbing across [0..arena.offset], unmaps the backing virtual memory pages via sys_munmap(arena.buffer, arena.capacity), and resets all struct fields to 0. Compile-time EscapeValidator treats attempts to read pointers allocated from this arena after deinit as fatal (CWE-416 Use-After-Free).

Example: Regional Memory Allocation & CWE-14 Scrubbing
SRC: arena_usage.oc 
import "std/mem.oc";

fn main() {
    // 1. Initialize a 64 KB regional arena backed by sys_mmap
    let mut arena: Arena = arena_init(65536);

    // 2. Fast bump allocation (0.00ns metadata overhead)
    let chunk: *mut u8 = arena_alloc(&mut arena, 16);
    chunk[0] = 79; // 'O'
    chunk[1] = 67; // 'C'
    print(chunk[0]);
    print(chunk[1]);

    // 3. Reset arena (scrubs memory with zeroes, resets bump pointer)
    arena_reset(&mut arena);

    // 4. Deallocate and return pages to kernel
    arena_deinit(&mut arena);
    print("Arena deallocated safely.");
}
TERMINAL: Output 
$ occ run arena_usage.oc
79
67
Arena deallocated safely.
Lifetime Invariant: Attempting to access chunk[0] after arena_reset(&mut arena) or arena_deinit(&mut arena) causes occ to reject compilation with error: use-after-free: variable 'chunk' used after arena 'arena' was reset/deinitialized.

OC-FS(3) — `std/fs.oc` Hardened File System I/O

The std/fs.oc module enforces active defense against TOCTOU symlink races (CWE-367 / CWE-59), file descriptor leaks into child processes (CWE-403), and missing path null-terminators (CWE-170).

cstr_path

fn cstr_path(path: string, out_buf: *mut u8) *u8

Mitigates CWE-170 (Improper Null Termination). Takes an immutable slice path: string, copies up to 4095 bytes into stack buffer out_buf: [4096]u8, and explicitly writes a terminating \0 at out_buf[len]. Guarantees kernel path arguments never read uninitialized stack bytes.

read_file

fn read_file(path: string, out_buf: *mut u8, max_len: usize) i64

Opens file at path with flags 0 | 655360 (O_RDONLY | O_NOFOLLOW | O_CLOEXEC). O_NOFOLLOW guarantees symlinks are rejected to prevent redirection attacks. O_CLOEXEC guarantees the descriptor is closed if execve is called. Reads up to max_len bytes into out_buf, closes the descriptor, and returns bytes read.

write_file

fn write_file(path: string, content: string) bool

Opens or creates file at path with flags 577 | 655360 = 655937 (O_WRONLY | O_CREAT | O_TRUNC | O_NOFOLLOW | O_CLOEXEC) and mode 420 (octal 0644). Writes content.len bytes directly via sys_write, safely closes the descriptor, and returns true if all bytes were written.

chmod_exec

fn chmod_exec(path: string) bool

Changes permissions of the target file to executable (mode 493 decimal = 0755 octal) via sys_chmod. Returns true on success.

unlink_file

fn unlink_file(path: string) bool

Removes the target file from the filesystem using sys_unlink. Returns true if unlinking succeeded.

Example: Atomic File Write, Hardened Read & Unlink
SRC: secure_fs.oc 
import "std/fs.oc";

fn main() {
    let file_path: string = "/tmp/oc_secure.txt";
    
    // 1. Atomic write with O_NOFOLLOW | O_CLOEXEC (CWE-367 / CWE-403)
    let written: bool = write_file(file_path, "oC Active-Defense Filesystem");
    print("File write status:");
    print(written);

    // 2. Safe read with 4096-byte bounded path buffer (CWE-170)
    let mut buf: [64]u8 = [0];
    let bytes: i64 = read_file(file_path, (&mut buf).as(*mut u8), 63);
    if bytes > 0 {
        buf[bytes.as(usize)] = 0;
        print("Read content:");
        print(buf);
    }

    // 3. Securely unlink temporary artifact
    let unlinked: bool = unlink_file(file_path);
    print("Unlink status:");
    print(unlinked);
}
TERMINAL: Output 
$ occ run secure_fs.oc
File write status:
true
Read content:
oC Active-Defense Filesystem
Unlink status:
true
Linear Resource Analysis: In oC, file descriptor lifecycles are linear. Attempting to close an already closed descriptor triggers double-close detection (CWE-415 / CWE-675), while functions returning without closing handles trigger resource leak diagnostics (CWE-404 / CWE-775).

OC-IO(3) — `std/io.oc` Tainted Input & Safe Output

The std/io.oc module handles standard streams without format string vulnerabilities (CWE-134). All external user input is tagged with taint flow tracking (CWE-20) to prevent unvalidated input from reaching sensitive sinks.

print / println

fn print(val: T) void
fn println(s: []u8) void

Safe stdout emitter. Emits slices, strings, integers, and booleans directly via sys_write(1, ...). Because print does not accept runtime C-style format strings (%s, %n), format string injection (CWE-134) is impossible by construction.

read_int

fn read_int() i32

Reads characters directly from standard input (fd = 0) using sys_read, filters ASCII characters between '0' (48) and '9' (57), and builds an integer. Ignores trailing newlines and non-numeric characters. The returned integer is marked tainted in the compiler's dataflow engine until checked against boundary constraints.

Example: Formatted Stream I/O & Numeric Extraction
SRC: io_demo.oc 
import "std/io.oc";

fn main() {
    print("Enter numeric configuration port: ");
    let port: i32 = read_int();
    print("Parsed configuration integer:");
    print(port);
}
TERMINAL: Interactive Run 
$ occ run io_demo.oc
Enter numeric configuration port: 8080
Parsed configuration integer:
8080
Dataflow Taint Tracking: Slices read via sys_read or read_int are marked with TAINTED_BIT. The compiler prevents passing tainted variables into unchecked sinks (e.g. file paths or slice indices) without an explicit sanitization barrier.

OC-NET(3) — `std/net.oc` Raw Socket & Wire Primitives

The std/net.oc module exposes raw Linux socket syscalls and byte-order serialization utilities for network protocol implementations and security probes.

packed struct sockaddr_in

packed struct sockaddr_in { sin_family: u16, sin_port: u16, sin_addr: u32, sin_zero: [8]u8 }

16-byte packed structure matching the Linux kernel struct sockaddr_in memory layout. The packed keyword prevents the compiler from inserting alignment padding bytes, preventing uninitialized memory disclosures (CWE-200) across socket boundaries.

htons

fn htons(hostshort: u16) u16

Converts 16-bit integer values from host byte order (little-endian on x86_64) to network byte order (big-endian) by transposing the high and low bytes.

probe_port

fn probe_port(port: u16) bool

Creates an AF_INET (2) TCP socket via sys_socket(2, 1, 0), configures sockaddr_in to target localhost (127.0.0.1 = 0x0100007f) on htons(port), attempts sys_connect, and immediately closes the socket with sys_close. Returns true if the port is open and listening.

Example: Network Socket Prober & Big-Endian Wire Conversion
SRC: net_probe.oc 
import "std/net.oc";

fn main() {
    let p: u16 = 8080;
    let net_order: u16 = htons(p);
    print("Host order 8080 to network order:");
    print(net_order);

    // Probe local port for listener (e.g. port 9999)
    let is_listening: bool = probe_port(9999);
    print("Port 9999 active:");
    print(is_listening);
}
TERMINAL: Output 
$ occ run net_probe.oc
Host order 8080 to network order:
36903
Port 9999 active:
false
ABI Wire Safety: sockaddr_in is declared packed so the compiler produces zero uninitialized padding gaps between sin_port and sin_addr, eliminating kernel/stack information leaks (CWE-200 / CWE-457).

OC-MATH(3) — `std/math.oc` Checked Mathematical Helpers

The std/math.oc module provides numerical utilities that cooperate with the compiler's hardware overflow detection.

abs_i32

fn abs_i32(x: i32) i32

Returns the absolute value of signed 32-bit integer x.
Hardware Overflow Trap Note (CWE-190): In traditional C, evaluating abs(-2147483648) triggers undefined behavior and silently returns -2147483648 because 2147483648 cannot be represented in a 32-bit signed integer. In oC, negating -2147483648 activates the CPU's Overflow Flag (OF=1), instantly executing jo __trap_overflow (hardware ud2 exception) rather than silently returning corrupted numbers.

min_u32 & max_u32

fn min_u32(a: u32, b: u32) u32
fn max_u32(a: u32, b: u32) u32

Branchless and checked boundary selection routines. Evaluates minimum and maximum without type coercion or sign extension errors.

align_forward

fn align_forward(addr: usize, alignment: usize) usize

Computes the next multiple of alignment greater than or equal to addr. Essential for hardware-aligned memory allocation in custom arena buffers.

Example: Memory Alignment & Checked Absolute Values
SRC: math_demo.oc 
import "std/math.oc";

fn main() {
    let aligned: usize = align_forward(17, 8);
    print("Align 17 forward to 8-byte boundary:");
    print(aligned); // 24

    let abs_val: i32 = abs_i32(-42);
    print("Absolute value of -42:");
    print(abs_val); // 42

    let minimum: u32 = min_u32(100, 45);
    print("min_u32(100, 45):");
    print(minimum); // 45
}
TERMINAL: Output 
$ occ run math_demo.oc
Align 17 forward to 8-byte boundary:
24
Absolute value of -42:
42
min_u32(100, 45):
45
Overflow Boundary Invariant: Testing abs_i32(-2147483648) triggers jo __trap_overflow, terminating execution immediately with a SIGILL / hardware trap. Silent numerical corruption is strictly eliminated.
