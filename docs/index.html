Why oC Exists

Traditional heap allocators (ptmalloc, jemalloc, mimalloc) interleave inline chunk metadata or freelist pointers with application data, enabling Use-After-Free (CWE-416), Double-Free (CWE-415), and Heap Metadata Corruption (CWE-122). Garbage collectors add latency spikes, while borrow checkers often force complex lifetime annotations across every struct.

oC eliminates the general-purpose heap entirely: 

// 1. Deterministic kernel-backed regional arenas via direct sys_mmap (0x0f 0x05)
let mut arena: Arena = arena_init(65536);
let buf: *mut u8 = arena_alloc(&mut arena, 256);

// 2. Compile-Time EscapeValidator blocks UAF & Cross-Arena Escapes before codegen
arena_deinit(&mut arena); // Automatically zeroes [0..arena.offset] (CWE-14) + sys_munmap
