DESCRIPTION

Traditional systems software written in C/C++ suffers from deep architectural security vulnerabilities originating from the general-purpose heap allocator (e.g., ptmalloc, jemalloc). By interleaving in-band chunk headers, forward/backward freelist pointers, and application buffers in shared memory, any out-of-bounds write or use-after-free escalates into arbitrary code execution.

oC replaces the fragile heap paradigm with deterministic regional arenas and compile-time escape analysis:

  • Zero General-Purpose Heap: All dynamic memory allocations are serviced by explicit kernel-backed regional bump arenas (sys_mmap). Zero inline chunk headers exist to be corrupted.
  • Compile-Time EscapeValidator: Temporal memory safety (UAF, double-free, dangling stack pointers) is validated statically at compile time with 0.00 ns runtime overhead.
  • Hardware-Enforced Traps: Arithmetic overflow (jo), division by zero (test + jz), null pointer dereferences, and slice out-of-bounds reads/writes trigger immediate hardware traps before arbitrary behavior can occur.
  • Standalone Static ELF Emission: occ --backend native directly emits standalone, statically linked Linux x86_64 ELF binaries under 5.0 KB without requiring GCC, Clang, or libc.

INTERACTIVE EXAMPLE (TRY-IT STATIC CARD)

Below is a self-contained oC program demonstrating regional arena management, hardware bounds checks, and CWE-14 secret scrubbing upon deinitialization:

Example: Arena Memory & Safe Fat Slices
SRC: arena_demo.oc oC Source 
import "std/io.oc";
import "std/mem.oc";

fn main() i32 {
    // 1. Allocate a 64 KB kernel-backed arena via direct sys_mmap
    let mut arena: Arena = arena_init(65536);

    // 2. Bump allocate 256 bytes for secure payload
    let buf: *mut u8 = arena_alloc(&mut arena, 256);
    buf[0] = 0x4F; // 'O'
    buf[1] = 0x43; // 'C'

    print("✔ Allocated 256 bytes. Current arena offset:");
    print(arena.offset);

    // 3. Reset scrubs all bytes [0..arena.offset] to zero (CWE-14)
    arena_reset(&mut arena);
    print("✔ Arena reset: memory zeroed, offset restored to 0");

    // 4. Deinit unmaps arena from kernel via sys_munmap
    arena_deinit(&mut arena);
    return 0;
}

How It Works: arena_init maps anonymous kernel pages via sys_mmap (0x0f 0x05). The bump allocator increments arena.offset in constant O(1) time. When done, arena_reset performs a linear scrub across the active region to neutralize CWE-14 information disclosure before resetting the pointer.
