oC v1.0 Language & Syntax Reference

Minimalist, unambiguous systems syntax designed for zero hidden control flow, explicit mutability, and hardware-checked safety invariants.

1. Primitive Types & Pointers

Category Types Representation
Unsigned Integers u8, u16, u32, u64, usize Exact-width unsigned integers (checked casts via .as(T))
Signed Integers i8, i16, i32, i64 Two's complement signed integers (hardware overflow traps)
Booleans & Strings bool, string bool (1B), string (16B fat slice { ptr: *u8, len: usize })
Pointers & Borrows *T, *mut T, &T, &mut T Non-owning pointers/references verified by EscapeValidator
Fixed Arrays [N]T Zero-initialized inline stack or struct arrays (e.g., [4096]u8)

2. Variables, Functions & Control Flow

Bindings are immutable by default (`let`) and require `let mut` for mutation.

import "std/mem.oc";
import "std/fs.oc";

let MAX_CONNECTIONS: u32 = 128;

fn fib(n: u64) -> u64 {
    if n <= 1 {
        return n;
    }
    return fib(n - 1) + fib(n - 2);
}

fn main() -> i32 {
    let mut acc: u64 = 0;
    let mut i: u64 = 0;
    while i < 10 {
        acc = acc + fib(i);
        i = i + 1;
    }
    print(acc);
    return 0;
}

3. Structs & Packed Wire Layouts

Struct literals zero-initialize all alignment padding (`CWE-200`). Use `packed struct` for exact kernel ABI and network packet headers. 

struct SensorReading {
    id: u32,
    flags: u8,
    payload: string,
}

packed struct sockaddr_in {
    sin_family: u16,
    sin_port: u16,
    sin_addr: u32,
    sin_zero: [8]u8,
}

4. Slices, Sub-Slicing & Checked Casts

Slice indexing `s[idx]` and sub-slicing `s[start..end]` emit hardware bounds traps (`__trap_slice_bounds`). Numeric casts `.as(T)` trap on negative-to-unsigned conversion (`CWE-195`) and narrowing truncation (`CWE-197`). 

let msg: string = "Native oC Systems";
let sub: string = msg[0..9]; // "Native oC" (traps if start > end or end > msg.len)
let ch: u8 = sub[0];         // 78 ('N')

let raw_len: usize = sub.len;
let safe_u16: u16 = raw_len.as(u16); // Checked narrowing cast

5. Regional Arenas (`std/mem.oc`)

All dynamic allocation uses deterministic bump arenas backed directly by Linux `sys_mmap`. Resetting or deinitializing an arena scrubs active memory (`CWE-14`) and invalidates all borrows at compile time (`CWE-416`). 

let mut arena: Arena = arena_init(65536);
let chunk: *mut u8 = arena_alloc(&mut arena, 128);
chunk[0] = 0x4F;

arena_reset(&mut arena);  // Scrubs bytes [0..offset] and invalidates `chunk` at compile time
arena_deinit(&mut arena); // Scrubs bytes and unmaps via sys_munmap

6. Direct Linux x86_64 Syscall Intrinsics

In `--backend native`, syscall intrinsics emit raw x86_64 `syscall` (`0x0f 0x05`) instructions with zero `libc`: 

extern fn sys_read(fd: i32, buf: *mut u8, count: usize) -> i64;
extern fn sys_write(fd: i32, buf: *u8, count: usize) -> i64;
extern fn sys_open(path: *u8, flags: i32, mode: u32) -> i32;
extern fn sys_close(fd: i32) -> i32;
extern fn sys_mmap(addr: usize, len: usize, prot: i32, flags: i32, fd: i32, off: usize) -> *mut void;
extern fn sys_munmap(addr: *mut void, len: usize) -> i32;
extern fn sys_socket(domain: i32, sock_type: i32, protocol: i32) -> i32;
extern fn sys_connect(fd: i32, addr: *sockaddr_in, len: u32) -> i32;
extern fn sys_chmod(path: *u8, mode: u32) -> i32;

extern fn sys_exit(code: i32);
